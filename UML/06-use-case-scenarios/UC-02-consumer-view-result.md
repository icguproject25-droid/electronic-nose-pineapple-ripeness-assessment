# UC-02 消費者查看成熟度結果

## 1. 使用案例名稱
消費者查看成熟度結果

## 2. 案例簡述
消費者於掃描完成後查看系統回傳之鳳梨成熟度分類、信心值與食用建議。

## 3. 參與角色
- 主要角色：消費者
- 次要角色：App、後端 API、模型推論系統

## 4. 前提
- 消費者已完成一次鳳梨掃描。
- 後端 API 已回傳模型推論結果。
- App 可正常解析結果資料。

## 5. 成功條件
- 系統成功顯示熟度分類。
- 系統成功顯示信心值。
- 系統成功顯示食用或保存建議。
- 該筆結果可儲存至歷史紀錄。

## 6. 主要路徑：正常情節
1. TUCBW：系統完成鳳梨成熟度推論。
2. App 接收後端回傳的 JSON 結果。
3. App 解析成熟度 Stage、信心值與建議內容。
4. 系統依照 Stage 顯示對應顏色標籤。
5. 系統顯示信心值百分比。
6. 系統顯示食用或保存建議。
7. 消費者查看結果。
8. TUCEW：系統將該筆結果儲存至歷史紀錄。

## 7. 例外路徑

### A1：後端沒有回傳結果
1. App 等待後端回應逾時。
2. 系統顯示「無法取得檢測結果」。
3. 消費者可選擇重新掃描。

### A2：JSON 格式錯誤
1. App 接收到格式不完整或欄位缺漏的資料。
2. 系統無法解析成熟度結果。
3. 系統顯示「結果格式錯誤，請重新檢測」。

### A3：信心值過低
1. 系統偵測到模型信心值低於可接受範圍。
2. 系統顯示「辨識信心值較低」提示。
3. 系統建議使用者重新掃描以取得更穩定結果。

### A4：結果儲存失敗
1. 系統顯示結果成功，但儲存歷史紀錄時發生錯誤。
2. 系統顯示「結果儲存失敗」。
3. 消費者仍可查看當前結果，但該筆資料不會出現在歷史紀錄中。
