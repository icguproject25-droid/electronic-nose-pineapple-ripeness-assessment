# PineNose｜賽後系統優化紀錄

**PineNose – Post-Competition System Optimization**

## 專案說明

PineNose 為本團隊開發之鳳梨電子鼻非破壞性熟度辨識系統，整合氣體感測、機器學習模型、嵌入式裝置、網頁平台及雙端手機 App，提供鳳梨熟度辨識與相關資訊管理功能。

本系統於參賽前即已完成主要功能之研發、整合與實作，並以既有系統成果參與競賽。

競賽結束後，團隊參考主辦單位及評審所提供的建議，針對既有系統進行進一步調整與優化，以改善實際使用情境下的操作流程、系統穩定性及整體使用體驗。

本資料夾主要用於整理及保存賽後的優化內容、相關程式與更新紀錄，作為後續系統維護、功能改善及專題延伸開發之參考。

## 優化方向

賽後優化以原有系統架構為基礎，依據實際測試結果與使用需求，逐步調整以下項目：

### 1. 感測與模型推論流程

針對感測資料的擷取、處理及模型推論流程進行檢查與調整，改善實際裝置運作時可能遇到的問題，並提升整體流程的一致性與穩定性。

### 2. 嵌入式裝置與系統整合

持續調整 Raspberry Pi、Arduino 與相關服務之間的資料傳輸及執行流程，減少系統操作過程中的異常情況，並改善各模組之間的整合。

### 3. 手機 App 功能與操作體驗

依據競賽建議及實際使用情境，持續檢視農業端與消費端 App 的功能、介面配置及操作流程，進行必要的功能調整與使用體驗改善。

### 4. 網頁平台與資料管理

針對既有網頁平台、後端服務及資料管理功能進行維護與調整，改善系統整合、資訊呈現及資料處理流程。

### 5. 系統測試與後續維護

透過實際操作與測試，檢查各項優化內容是否能正常運作，並保留相關程式、測試結果及更新紀錄，方便後續追蹤與維護。

## 資料夾內容

本資料夾將依實際優化進度，陸續整理以下相關資料：

- Raspberry Pi 與感測裝置相關程式及調整紀錄
- 模型推論流程與相關測試工具
- 農業端及消費端手機 App 優化內容
- 網頁平台與後端整合調整
- 系統測試、問題修正及相關文件

各項內容將依功能與版本分別保存，實際檔案及目錄結構以後續更新為準。

## 開發與版本說明

本資料夾所收錄之內容，主要為競賽結束後，團隊根據主辦單位及評審建議所進行的後續優化。

PineNose 原有系統及主要功能均於參賽前完成研發，本資料夾之更新不代表系統於賽後才開始開發。

相關調整以原有系統為基礎，並依照實際需求持續改善。部分功能可能仍處於測試、調整或整合階段，應以各子資料夾及版本紀錄中的說明為準。

## 後續規劃

團隊將持續依據實際測試與使用回饋，改善系統操作流程、各模組之間的整合及使用體驗，並視需求評估後續功能擴充的可行性。

本資料夾亦作為 PineNose 畢業專題後續維護與開發紀錄的一部分，保留團隊在完成原有系統後，持續檢討問題並進行改善的過程。
